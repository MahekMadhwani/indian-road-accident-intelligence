# Indian Road Accident Intelligence
### A National Road Safety Analytics Dashboard (2021–2024)

## Project Overview
This project uses Microsoft Power BI to analyze road accident data in India
from 2021 to 2024. The dashboard presents data through visualizations
to make road safety patterns easier to explore.

## Objectives
- Analyze road accident patterns over time.
- Present key road safety metrics in a visual format.
- Compare the dimensions available in the dataset.
- Support data-driven road safety analysis.

## Tools Used
- Microsoft Power BI Desktop
