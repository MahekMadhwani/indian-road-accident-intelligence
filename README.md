# Indian Road Accident Intelligence
### A National Road Safety Analytics Dashboard (2021–2024)

## Project Overview
This project uses Microsoft Power BI to analyze road accident data in India
from 2021 to 2024. The dashboard presents data through visualizations
to make road safety patterns easier to explore.

## Objectives
- Analyze road accident patterns over time.
- Present key road safety metrics in a visual format.
- Compare the dimensions available in the dataset.
- Support data-driven road safety analysis.

## Key Findings

- **Accident Trends:** Road accidents peaked in 2022 at approximately 213K cases, followed by a gradual decline in 2023 and 2024.

- **State-wise Analysis:** Tamil Nadu recorded the highest number of road accidents, followed by Madhya Pradesh, Uttar Pradesh, Karnataka, and Kerala.

- **Overall Impact:** The dashboard recorded approximately 824.5K road accidents, 3,524.2K persons injured, and 1,345.1K persons killed across the 2021–2024 period, according to the displayed KPI metrics.
